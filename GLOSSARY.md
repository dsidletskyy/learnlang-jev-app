# Language Learning

Personal dictionaries support practice recalling phrases from their translations.

## Language

**Dictionary**:
A user's collection of phrase–translation pairs.

**Dictionary entry**:
One original phrase and its language paired with a translation in a user's dictionary.

**Learning session**:
A practice session in which a user recalls original phrases of a selected language from translations, with each matching entry presented once in random order.

**Meaning-match score**:
An estimated percentage expressing how closely an answer's meaning matches the original phrase.

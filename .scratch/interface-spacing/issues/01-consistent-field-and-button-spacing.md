# 01: Consistent field and button spacing

**What to build:** Make the fields in the Add/Edit Dictionary entry dialog easy to distinguish. Give action buttons consistent spacing across the app, including on narrow screens.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The Add and Edit Dictionary entry dialog uses a 1rem gap between field groups and a 0.5rem gap between each label and its control.
- [ ] Field validation messages stay with their fields; validation behavior and accessibility are unchanged.
- [ ] Adjacent action buttons across the app have a 0.5rem gap and wrap on narrow screens.
- [ ] Existing button behavior and keyboard access remain unchanged.
- [ ] Tests cover field spacing and action button spacing, including a narrow viewport.

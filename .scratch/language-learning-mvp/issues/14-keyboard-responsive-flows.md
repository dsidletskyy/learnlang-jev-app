# 14: Verify keyboard and narrow-window flows

**What to build:** A learner can use dictionary and learning flows comfortably with a keyboard and in narrow windows.

**Blocked by:** 05: Review dictionary entries; 06: Edit a dictionary entry; 07: Delete a dictionary entry; 09: Finish and review a learning session; 11: Recover from evaluation failure; 12: Leave an unfinished session safely

**Status:** ready-for-agent

- [ ] Use a calm minimal light theme with muted blue accents, readable wrapping, responsive stacking and no horizontal scrolling; show full multiline content.
- [ ] Verify keyboard navigation, visible focus, accessible dialog focus behavior, appropriately sized touch targets, and labeled edit/delete icon buttons with hover tooltips.
- [ ] Run behavioral and keyboard tests across Chromium, Firefox and WebKit targeting WCAG 2.2 AA; do not add an accessibility scanner or claim verified conformance from automated tests.

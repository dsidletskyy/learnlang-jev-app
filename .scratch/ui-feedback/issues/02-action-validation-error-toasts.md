# 02: Show action and validation error toasts

**What to build:** Show a Sonner error toast when a dictionary entry or learning session action fails, or when submitted input fails validation. Help users identify and correct invalid fields.

**Blocked by:** 01: Show dictionary entry success toasts.

**Status:** ready-for-agent

- [ ] Failed dictionary entry saves and deletions, learning session loading, and answer evaluation show an error toast with useful recovery information.
- [ ] Invalid submitted fields show an error toast and retain field-specific inline guidance.
- [ ] Error toasts remain visible until manually dismissed and fit the existing color theme.
- [ ] Error feedback remains accessible, including when an action occurs inside a modal dialog.
- [ ] Automated tests cover representative dictionary entry and learning session errors, validation, and toast dismissal.
